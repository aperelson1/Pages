## Current Project

  I am currently working on a simple website for a friend to publicly share his skateboard videography. The structure is a frontend built with React which consumes REST endpoints exposed by the backend. The backend is built with Java and SpringBoot and connected to a MySQL database that contains video entities. Users can search for videos by title, skateboarder, location, or tags. Once he settles on a name and we sign up for a video CDN, the site will take its final shape and be populated with some of the hundreds of hours of footage he has.
